# Concordia Triglotta (1921)

This directory contains a searchable OCR transcription of the complete 1921 *Concordia Triglotta: The Symbolical Books of the Evangelical Lutheran Church, German-Latin-English*, published in St. Louis by Concordia Publishing House.

## Files

- `concordia-triglotta-1921-ocr.txt` — complete German, Latin, and English OCR text derived from the Internet Archive scan.

The OCR file preserves scanning errors from the source derivative. When exact wording matters, compare it with the page images. The English Small Catechism begins near line 113,113 of the OCR file (printed page 531; scan page 817).

## Use in the Svebilius translation

The Triglotta is a terminology and style reference, not the base text for the Svebilius translation. The English Svebilius files remain translations of the Finnish Svebilius text, including material and formulations that differ from the Triglotta.

For terms shared with the Triglotta, the English Svebilius translation follows its established usage where doing so does not change Svebilius's meaning. In particular, the translation consistently uses `Holy Ghost`, including in Trinitarian formulas, article headings, and references to the Third Person of the Trinity. Contextual biblical expressions such as `Spirit of God`, `Spirit of His Son`, and the lowercase wording of the King James Version in Psalm 51 are preserved as quoted.
